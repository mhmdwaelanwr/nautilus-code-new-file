# Nautilus Code New File 🛠️

A smart Nautilus extension for Ubuntu/Debian that adds a categorized right-click menu to quickly create developer files with a custom naming prompt.

<p align="center">
  <img src="assets/demo.gif" alt="Extension Demo" width="30%">
</p>

## 🚀 Quick Installation

Run this one-liner in your terminal to install it instantly:

```bash
curl -sSL https://raw.githubusercontent.com/mhmdwaelanwr/nautilus-code-new-file/main/install.sh | bash
```

## ✨ Features
* Categorized clean menu for fast developer file generation.
* Built-in Zenity pop-up to instantly set custom file names.
* Integrates natively into the Ubuntu desktop right-click menu.

## 🗑️ Uninstall

```bash
rm ~/.local/share/nautilus-python/extensions/nautilus-code-new-file.py
nautilus -q
```
