# Roadmap

## Near term

- Test and document compatibility across current Ubuntu/Debian releases.
- Add installation notes for Fedora and Arch-based distributions.
- Improve error feedback when a requested file already exists.
- Add a small automated syntax check for the Python extension and installer.
- Keep the supported file-template list focused and easy to navigate.

## Community ideas

Contributions are welcome for compatibility testing, documentation, new file types, and small usability improvements. Please open an issue before large behavioral changes so the scope stays focused.
